# Roadmap & Future Vision

SwiftJS is a rapidly evolving framework. This roadmap outlines where we are and where we’re going.

## Current State (v0.9.0)
We are currently in a "Pre-Stable" phase. 
- **Core Stablity**: The Radix Router and DI Container are considered production-ready.
- **Runtime Support**: Full Node.js and Bun support is verified.
- **Feature Set**: Authentication, Validation, Jobs, and Storage plugins are functional.

## The Road to v1.0 (The Stable Horizon)

- **API Stability Guarantee**: Locking down the core API to prevent breaking changes for at least 12 months.
- **Performance Benchmarks**: Reaching and verifying ~50k req/s for static paths.
- **Official Masterclass**: A comprehensive video series to lower the barrier for traditional Backend engineers.
- **Expansion of Adapters**: Native support for Deno and Vercel Edge.

## Future Vision (Post v1.0)

### Streaming AI Revolution
First-class support for LLM streaming, token counting, and simplified proxying for OpenAI/Anthropic/Gemini.

### Edge-First Distributed State
A unified API for sharing state globally across edge instances without managing complex database clusters manually.

### Zero-Config Multi-Cloud
Automatic scaling and deployment targets based on traffic patterns and geographic spikes.
