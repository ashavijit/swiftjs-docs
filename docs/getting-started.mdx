# Getting Started

SwiftJS is a high-performance, type-safe web framework for Node.js, Bun, and Edge runtimes. It combines the developer experience of modern frameworks with raw performance that rivals Fastify.

## Installation

The best way to start a new project is using `create-swiftjs-app`. This CLI tool sets up a complete project with TypeScript, linting, and your choice of template.

```bash
npx create-swiftjs-app my-app
```

Follow the interactive prompts to choose a template:
- **Basic API:** Simple REST API setup
- **File Router:** Next.js-style file-based routing
- **AWS Lambda:** Serverless-ready setup

Alternatively, you can install the core package manually in an existing project:

```bash
npm install swiftjs-core
```

## Quick Start

Here's a minimal "Hello World" application using SwiftJS:

```typescript
import { createApp } from 'swiftjs-core';

// Create app instance
const app = createApp({
  port: 3000
});

// Define a route
app.get('/', () => ({
  message: 'Hello World!',
  timestamp: new Date().toISOString()
}));

// Start the server
app.listen().then(() => {
  console.log('🚀 Server running on http://localhost:3000');
});
```

## Key Concept: The Application Factory

SwiftJS uses a factory pattern `createApp()` instead of a singleton or class instantiation. This ensures:
1. **Type Safety:** Options are validated at creation
2. **Isolation:** Each app instance is independent
3. **Flexibility:** Easy to create multiple apps for testing

## Development

SwiftJS comes with a powerful CLI for development. If you used `create-swiftjs-app`, you can start the dev server with:

```bash
npm run dev
# or
swiftjs dev
```

This starts the server in development mode with:
- **Hot Reloading:** Changes are applied instantly
- **Dev Tools:** Request logging, timing, and debugging info
- **TypeScript:** Built-in TypeScript support via `tsx`

## Production Build

To build for production:

```bash
npm run build
# or
swiftjs build
```

Then start the production server:

```bash
npm start
# or
swiftjs start
```

In production mode:
- Dev tools are disabled for performance
- Logging is minimized
- Optimizations like lazy body parsing are enabled automatically
