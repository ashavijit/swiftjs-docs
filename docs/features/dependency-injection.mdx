# Dependency Injection

SwiftJS includes a lightweight, type-safe Dependency Injection (DI) container to help structure your application and manage dependencies.

## Basic Usage

Access the container via `app.container`.

```typescript
import { createApp } from 'swiftjs-core';

const app = createApp();

// Register a service
class ApiService {
  async getData() {
    return 'data';
  }
}

app.container.register('apiService', new ApiService());

// Resolve it later
const apiService = app.container.resolve<ApiService>('apiService');
```

## Factory Registration

You can register factories that are instantiated on demand.

```typescript
app.container.registerFactory('logger', container => {
  return createLogger();
});
```

## Singleton Registration

You can register singletons that are created once and reused.

```typescript
app.container.registerSingleton('db', DatabaseClient);
```

## Usage in Handlers

The container is available in the request context (via middleware or custom extensions, depending on your setup pattern) but generally, you resolve dependencies during app startup and pass them to your route factories or plugins.

```typescript
// src/services/user-service.ts
export class UserService {
  constructor(private db: Database) {}
  // ...
}

// src/index.ts
const db = new Database();
const userService = new UserService(db);

app.container.register('userService', userService);

// src/routes/users.ts
// Access via global container or passed context if architected that way
```
