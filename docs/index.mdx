# SwiftJS

SwiftJS is a TypeScript-first web framework designed for building fast, scalable APIs with excellent developer experience.

## Key Features

- **Ultra High Performance** - 53k+ req/sec (Node.js), matching Hono and Fastify.
- **Hybrid Sync/Async Router** - Zero-allocation hot paths for synchronous routes.
- **Multi-Runtime Support** - Run on Node.js, Bun, or Edge (Lambda, Cloudflare) with automatic detection.
- **TypeScript-First** - Full type safety with excellent IDE support and Zod integration.
- **File-Based Routing** - Next.js-style automatic route discovery with dynamic parameters.
- **Schema Validation** - Powerful request validation for body, query, and params using Zod.
- **Plugin System** - Extensible architecture with lifecycle hooks (onStart, onRequest, etc.).
- **Auto API Documentation** - Built-in support for Swagger UI, ReDoc, Scalar, and Stoplight.
- **Observability** - Native Prometheus metrics, OpenTelemetry tracing, and health checks.
- **Security** - CSRF protection, security headers, request signing, and SQL injection detection.
- **Jobs & Scheduling** - Built-in task scheduler for Cron, interval, and delayed jobs.
- **Real-time** - Seamless WebSocket and Server-Sent Events (SSE) support.
- **Database Integration** - First-class support for Prisma, Drizzle, and a built-in MemoryDB.

## Installation

```bash
npm install swiftjs-core zod
```

## Minimal Example

```typescript
import { createApp } from 'swiftjs-core';

const app = createApp({ port: 3000 });

app.get('/', () => ({ message: 'Hello SwiftJS!' }));

app.listen();
```

## Requirements

- Node.js >= 18.0.0 or Bun >= 1.0.0
- TypeScript >= 5.0.0
