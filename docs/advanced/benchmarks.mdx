# SwiftJS vs Other Node.js Frameworks

This comparison focuses on **raw HTTP performance, latency stability, and scaling behavior**, not ecosystem size or DX.

All numbers are from:

- Single Node.js process
- Single core
- `NODE_ENV=production`
- Simple `GET / → "OK"`
- `autocannon` on localhost

## v0.7.0 Performance Optimizations

SwiftJS achieved a **~3x - 5x performance jump** in version 0.7.0 by implementing advanced routing techniques:

### 1. Hybrid Sync/Async Router

Most Node.js frameworks force every request into an `async/await` promise chain. SwiftJS v0.7 introduces a **Dual Execution Mode**:

- **Sync Path**: If a route handler is synchronous (e.g., simple GET), the router executes it immediately without allocating a Promise.
- **Async Path**: Only allocates Promises when `async` handlers or middleware are actually used.
- **Result**: **Zero-allocation** routing for hot paths.

### 2. Pre-Computed Response Headers

Common response types (JSON, Text, HTML) use pre-allocated static header objects. This avoids creating new objects for `Content-Type` on every single request, reducing Garbage Collection pressure significantly.

### 3. Inline Path Parsing

The router now handles path parsing (query string separation) inline optimization, reducing function call overhead in the request hot path.
