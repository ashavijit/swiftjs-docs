# Deployment

SwiftJS is designed for modern infrastructure. Whether you are deploying to a traditional VPS, a containerized environment (Docker), or an Edge runtime, this guide covers the best practices.

## Environment Preparation

Before deploying, ensure you have set your production environment variables.

```env
NODE_ENV=production
PORT=3000
DATABASE_URL=...
JWT_SECRET=...
```

## Docker Deployment (Recommended)

Docker is the preferred way to deploy SwiftJS apps, ensuring consistency across development and production.

### Dockerfile
```dockerfile
# Build stage
FROM oven/bun:latest as builder
WORKDIR /app
COPY package.json bun.lockb ./
RUN bun install --frozen-lockfile
COPY . .
RUN bun run build

# Production stage
FROM oven/bun:slim
WORKDIR /app
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/package.json ./package.json

ENV NODE_ENV=production
EXPOSE 3000

CMD ["bun", "dist/app.js"]
```

## Process Management (PM2)

If deploying to a VPS (Ubuntu/Debian) without Docker, use PM2 to manage your processes.

```bash
npm install -g pm2
pm2 start dist/app.js --name "swift-api" -i max
```

### PM2 Ecosystem File
```javascript
module.exports = {
  apps: [{
    name: "swift-api",
    script: "./dist/app.js",
    instances: "max",
    exec_mode: "cluster",
    wait_ready: true, // SwiftJS supports PM2 wait-ready signal
    env_production: {
      NODE_ENV: "production"
    }
  }]
}
```

## CI/CD Pipeline (GitHub Actions)

Example workflow to test and build your SwiftJS application on every push.

```yaml
name: CI
on: [push]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: oven-sh/setup-bun@v1
      - run: bun install
      - run: bun test
      - run: bun run build
```

## Edge Deployment

### Cloudflare Workers
SwiftJS provides a native adapter for Cloudflare Workers. Note that some features (like disk-based file uploads) are unavailable in the Edge runtime.

```typescript
import { Swift } from 'swiftjs-core';
import { CloudflareAdapter } from '@swiftjs/adapter-cloudflare';

const app = new Swift({ adapter: new CloudflareAdapter() });
export default app;
```

## Deployment Checklist

1. **Disable Development Logs**: Ensure logging level is set to `info` or `warn`.
2. **Enable Compression**: Use the `compression()` middleware to save bandwidth.
3. **Health Checks**: Implement a `GET /health` endpoint for load balancer monitoring.
4. **SSL/TLS**: Never serve raw HTTP. Use a reverse proxy (Nginx/Traefik) or a CDN (Cloudflare) for SSL.
