# API Reference

## createApp(config)

Creates a new SwiftJS application instance.

```typescript
import { createApp } from 'swiftjs-core';

const app = createApp({
  port: 3000,              // Port to listen on (default: 3000)
  routesDir: 'src/routes', // Directory for file-based routing
  env: 'development',      // 'development' | 'production' | 'test'
  trustProxy: true,        // Trust proxy headers (X-Forwarded-For)
  bodyLimit: '1mb',        // Request body size limit
  cookieSecret: 'secret'   // Secret for signing cookies
});
```

## Application Instance

### app.get(path, handler, config?)
Register a GET route.
- **path** (string): URL path pattern.
- **handler** (function): Async handler function.
- **config** (object, optional): Route configuration (validation, middleware).

Also available: `app.post`, `app.put`, `app.patch`, `app.delete`, `app.all`.

### app.use(middleware)
Register global middleware.

### app.register(plugin)
Register a plugin.

### app.listen()
Start the HTTP server. Returns a Promise.

### app.router
Access the underlying Radix Router instance.

## Context Object

The `ctx` object is passed to every handler and middleware.

### Request Properties

| Property | Type | Description |
|----------|------|-------------|
| `ctx.req` | IncomingMessage | Node.js IncomingMessage |
| `ctx.method` | string | HTTP method |
| `ctx.url` | string | Request URL |
| `ctx.path` | string | Request path |
| `ctx.query` | object | Parsed query parameters |
| `ctx.params` | object | Route parameters |
| `ctx.body` | any | Parsed request body |
| `ctx.headers` | object | Request headers |
| `ctx.ip` | string | Client IP address |

### Cookie Methods

- `ctx.cookies.get(name)` - Get a cookie value
- `ctx.cookies.getSigned(name)` - Get a signed cookie value
- `ctx.cookies.set(name, value, options?)` - Set cookie
- `ctx.cookies.delete(name)` - Delete cookie

### Response Methods

| Method | Description |
|--------|-------------|
| `ctx.json(data)` | Send JSON response (status 200 by default) |
| `ctx.text(string)` | Send plain text response |
| `ctx.html(string)` | Send HTML response |
| `ctx.status(code)` | Set HTTP status code (chainable) |
| `ctx.redirect(url, status?)` | Redirect to URL |
| `ctx.notFound(message?)` | Send 404 response |

### Response Headers

- `ctx.res.setHeader(name, value)` - Set response header

### State and Utils

- `ctx.state.get(key)` - Get value from request-scoped state
- `ctx.state.set(key, value)` - Set value in request-scoped state
- `ctx.logger` - Application logger instance

## Types

SwiftJS exports TypeScript types for all core objects.

```typescript
import type {
  Context,
  Handler,
  Middleware,
  Plugin,
  RouteConfig
} from 'swiftjs-core';
```
